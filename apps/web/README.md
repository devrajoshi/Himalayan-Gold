# 🌕 Himalayan Gold - Web Application

This is the primary customer-facing application for Himalayan Gold. It features a premium, immersive shopping experience and a comprehensive member dashboard.

## ✨ Key Features

- **Premium Storefront**: Immersive landing page with smooth animations and interactive hexagon backgrounds.
- **Product Details**: Detailed views of our wild, raw honey selections.
- **Member Dashboard**: A personalized area for members to:
  - View Order History
  - Manage Shipping Addresses
  - Track Honey Rewards & Membership Tier
  - Update Profile Details
- **Collapsible Sidebar**: Space-efficient navigation for the dashboard.
- **Interactive Backgrounds**: Dynamic hexagon grids that respond to user interaction.

## 🎨 Theme & Design

- **Primary Colors**: Forest Green (`#0D2F23`), Mountain Gold (`#D4AF37`), and Ecru.
- **Typography**: Display fonts for headings, clean sans-serif for body text.
- **Aesthetic**: Dark, luxurious, and natural.

## 🚀 Getting Started

From the root directory:

```bash
bun dev --filter=web
```

Or from this directory:

```bash
bun dev
```

## 🛠️ Built With

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: Vanilla CSS, Tailwind CSS
- **Interactivity**: Framer Motion
- **Icons**: Lucide React
